Эрдэм шинжилгээний өгүүлэл, хураангуй, диссертаци, судалгааны тайланг англи эсвэл монгол хэлээр бичих, засах, хянах ур чадвар (skill). K-Dense-ийн scientific-writing ур чадварын эх англи заавар дээр монгол хэлний заавар нэмсэн хувилбар.

Зохиогчийн эрх: © 2026 Center for Digital Health and Innovation.

## Гол чадвар

- Өгүүллийн хэсэг бүрийг эхлээд тоймоор, дараа нь үргэлжилсэн догол мөрөөр бичнэ.
- IMRaD болон монгол сэтгүүлийн («Лавай», MJER) бүтцээр зохион байгуулна.
- Монгол өгүүлэлд орос, англи хураангуй, түлхүүр үг бэлтгэнэ.
- Эшлэлийг APA, Vancouver, AMA, IEEE, Chicago, «Лавай»-н стандартаар хийж, монгол эх сурвалжийг MNS 5217:2012-оор галиглана.
- Судалгааны загварт тохирох тайлагнах удирдамжийг (CONSORT 2025, STROBE, PRISMA 2020, SPIRIT 2025, TRIPOD+AI г.м.) мөрдөнө.
- Өгүүллийг рецензент шиг хянаж, рецензентийн саналд хариу бичнэ.
- Эшлэл, тоо баримт зохиохгүй. Эх сурвалж дутуу газрыг «[эшлэл шаардлагатай]» гэж тэмдэглэнэ.

### Хэрхэн ажилладаг

Туслахын уншдаг үндсэн заавар (`SKILL.md`) англиар бичигдсэн тул хурдан ачаалагдана. Монгол хэлний заавар `references/mn/` хавтсанд монголоор байна. Монгол өгүүлэл бичих, монгол сэтгүүлд илгээх үед туслах монгол зааврыг, англи өгүүлэлд эх англи зааврыг уншина. Хариулт таны бичсэн хэлээр гарна.

## Суулгах заавар

Хэрэглэдэг хэрэгсэлдээ тохирох аргыг сонгоно уу.

### 1. Claude (вэб, компьютерийн апп)

1. Репозиторын сүүлийн хувилбарын `scientific-writing.zip` файлыг татаж авна.
2. Claude-ийн Customize цэсийг нээж, Plugins хэсгийг сонгоно.
3. Өргөтгөл нэмэх товчийг дарж, `scientific-writing.zip` файлыг задлахгүйгээр оруулна.
4. Plugins жагсаалтад `scientific-writing` гарч ирж, асаалттай байгааг шалгана.

Цэсний нэр апп-ын хувилбараас хамаарч өөр байж болно.

### 2. Claude Code

Терминалд дараах тушаалыг ажиллуулна:

```bash
mkdir -p ~/.claude/skills
unzip scientific-writing.zip -d ~/.claude/skills/
```

Өргөтгөл (plugin) болгон суулгах бол Claude Code-д дараах командыг бичнэ:

```text
/plugin marketplace add <таны-github-нэр>/scientific-writing
/plugin install scientific-writing@scientific-writing
```

### 3. ChatGPT, Gemini, бусад чатбот

1. Шинэ яриа эхлүүлж, `dist/scientific-writing-buten.md` файлыг хавсаргана.
2. Дараах хүсэлтийг илгээнэ:

   ```text
   Хавсаргасан файлын зааврын дагуу энэ өгүүллийн удиртгалыг бичээрэй:
   [сэдэв, зорилго, эх сурвалж]
   ```

Байнга хэрэглэх бол энэ файлыг Custom GPT, Gemini Gem эсвэл Project-ийн мэдлэгийн файл болгон оруулна уу.

### 4. Codex, Cursor, Gemini CLI

Репозиторыг GitHub-д байршуулсны дараа бүх төсөлд ажиллахаар дараах тушаалаар суулгана:

```bash
npx skills add <таны-github-нэр>/scientific-writing --global --agent '*'
```

> **Анхаар:** K-Dense-ийн эх scientific-writing эсвэл өмнөх scientific-writing-mn суусан бол түүнийг устгах эсвэл унтраах шаардлагатай. Нэр, хүсэлт нь давхцах тул туслах өөр ур чадварыг дуудаж болзошгүй.

## Хэрэглэх заавар

Хүсэлтээ доорх загвараар илгээнэ. `[ ]` доторхыг өөрийн мэдээллээр солино. Өгөгдөл, үр дүн, эх сурвалжаа хамт хавсаргана уу.

| Зориулалт | Хүсэлт |
|---|---|
| Бичих | `Удиртгал бичиж өг. Сэдэв: [...]. Зорилго: [...]. Эх сурвалж: [хавсралт]` |
| Засах | `Энэ хэлэлцүүлгийг сайжруулаач: [бичвэр]` |
| Хянах | `Энэ өгүүллийг рецензент шиг шалгаач, засахгүй: [бичвэр]` |
| Хураангуй | `Өгүүллийн монгол, орос, англи хураангуй, түлхүүр үгийг бэлтгэ: [бичвэр]` |
| Эшлэл | `Ном зүйг Vancouver стандартаар засаарай: [жагсаалт]` |
| Сэтгүүлд тааруулах | `«Лавай» сэтгүүлд илгээх гэж байна, шаардлагаар шалгаач: [бичвэр]` |
| Рецензийн хариу | `Рецензентийн санал, миний өгүүлэл хавсралтад байна. Хариу захидал бич.` |
| Удирдамжаар шалгах | `CONSORT 2025-аар шалгаад хяналтын хуудсыг бөглө: [бичвэр]` |
| Англиар бичих | `Write the abstract in English for an international journal: [бичвэр]` |

Claude дээр командаар шууд эхэлж болно: `/scientific-writing [хүсэлт]`. Өргөтгөлөөр суулгасан бол `/scientific-writing:scientific-writing [хүсэлт]`.

### Хүсэлтэд нэмж болох мөр

| Мөр | Үр дүн |
|---|---|
| `Сэтгүүл: «Лавай»` | Тухайн сэтгүүлийн шаардлагаар бичнэ |
| `Хэл: англи` | Өгүүллийг англиар бичнэ, хариулт монголоор гарна |
| `Эшлэл: APA 7` | Заасан стандартаар эшилнэ |
| `Судалгааны загвар: когорт` | Тохирох тайлагнах удирдамжийг (STROBE) мөрдөнө |
| `Үгийн хязгаар: 250` | Заасан хэмжээнд багтаана |
| `Тоймгүй, шууд бичвэр өг` | Тойм батлуулалгүй бэлэн бичвэрийг өгнө |

### Хариултын бүтэц

| Ажил | Хариулт |
|---|---|
| Бичих | Эхлээд хэсгийн тойм (та батална), дараа нь үргэлжилсэн бичвэр, эцэст нь таны шалгах, бөглөх зүйлсийн товч жагсаалт |
| Хянах | Ноцтой, бага, найруулгын санал, хэсэг тус бүрээр, засварын саналтай |
| Удирдамжаар шалгах | Зүйл бүр өгүүллийн аль хэсэгт байгааг заасан хяналтын хуудас, дутуу зүйлийн жагсаалт |

## Зөвлөмж

1. Өгөгдөл, үр дүн, эх сурвалжаа хавсаргана уу. Ур чадвар баримт зохиохгүй тул дутуу мэдээллийг тэмдэглээд үлдээнэ.
2. Илгээх сэтгүүлээ эхэнд нь хэлнэ үү. Сэтгүүлийн шаардлага ерөнхий зөвлөмжөөс давуу.
3. Эцсийн бичвэрийн эшлэл, тоо, статистикийг эх сурвалжтай нь тулгаж шалгана уу.
4. Хиймэл оюун ашигласан тухай сэтгүүлийн бодлогыг шалгана уу. Ихэнх сэтгүүл үүнийг мэдэгдэхийг шаарддаг, хиймэл оюуныг зохиогчоор бүртгэхийг зөвшөөрдөггүй.
5. Монгол бичвэрийн найруулгыг Humanizer эсвэл Humanizer-MN ур чадвараар эцэст нь нэг удаа шалгаж болно.
