# MN Scientific Writing

[![Version](https://img.shields.io/badge/version-2.2.0-blue.svg)](CHANGELOG.md)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Эрдэм шинжилгээний өгүүлэл, хураангуй, диссертаци, судалгааны тайланг англи эсвэл монгол хэлээр бичих, засах, хянах ур чадвар (skill). Эмч, эрүүл мэндийн судлаач, магистрант, докторантад зориулав. Олон улсын (Nature, The Lancet, NEJM, JAMA, BMJ г.м.) болон Монголын (CAJMS, «Эрүүл мэндийн шинжлэх ухаан», «Монголын анагаах ухаан» г.м.) сэтгүүлийн шаардлагаар ажиллана.

K-Dense-ийн scientific-writing ур чадварын эх англи заавар дээр монгол хэлний заавар нэмсэн хувилбар. Зохиогчийн эрх: © 2026 Цахим эрүүл мэнд инновацын төв (Center for Digital Health and Innovation).

## Гол чадвар

- Өгүүллийн хэсэг бүрийг эхлээд тоймоор, дараа нь үргэлжилсэн догол мөрөөр бичнэ.
- IMRaD болон монгол сэтгүүлийн («Лавай», MJER) бүтцээр зохион байгуулна.
- Монголын анагаах ухааны 10 сэтгүүлийн шаардлагаар, хэсэг бүрийн дэлгэрэнгүй загвараар бичнэ.
- Монгол өгүүлэлд орос, англи хураангуй, түлхүүр үг бэлтгэнэ.
- Эшлэлийг APA, Vancouver, AMA, IEEE, Chicago, «Лавай»-н стандартаар хийж, монгол эх сурвалжийг MNS 5217:2012-оор галиглана.
- Судалгааны загварт тохирох тайлагнах удирдамжийг (CONSORT 2025, STROBE, PRISMA 2020, SPIRIT 2025, TRIPOD+AI, CARE г.м.) мөрдөнө.
- Өгүүллийг рецензент шиг хянаж, рецензентийн саналд хариу бичнэ.
- Эшлэл, тоо баримт зохиохгүй. Эх сурвалж дутуу газрыг «[эшлэл шаардлагатай]» гэж тэмдэглэнэ.

### Хэрхэн ажилладаг

Туслахын уншдаг үндсэн заавар (`SKILL.md`) англиар бичигдсэн тул хурдан ачаалагдана. Монгол хэлний заавар `references/mn/` хавтсанд монголоор байна. Монгол өгүүлэл бичих, монгол сэтгүүлд илгээх үед туслах монгол зааврыг, англи өгүүлэлд эх англи зааврыг уншина. Хариулт таны бичсэн хэлээр гарна.

## Суулгах заавар

Хэрэглэдэг хэрэгсэлдээ тохирох аргыг сонгоно уу.

### 1. Claude (вэб, компьютерийн апп)

1. GitHub-ийн [cdhi-claude-skills](https://github.com/CDHI-Mongolia/cdhi-claude-skills) репозиторыг нээж, `mn-scientificwriting.zip` файлыг Download raw file товчоор татна.
2. Claude-ийн Customize цэсийг нээж, Plugins хэсгийг сонгоно.
3. Add, дараа нь Upload plugin дээр дарж, `mn-scientificwriting.zip` файлыг задлахгүйгээр оруулна.
4. Plugins жагсаалтад `mn-scientificwriting` гарч ирж, асаалттай байгааг шалгана.

Цэсний нэр апп-ын хувилбараас хамаарч өөр байж болно.

### 2. Claude Code

Claude Code-д дараах командыг бичнэ:

```text
/plugin marketplace add CDHI-Mongolia/cdhi-claude-skills
/plugin install mn-scientificwriting@cdhi-skills
```

Эсвэл терминалд:

```bash
mkdir -p ~/.claude/skills
unzip mn-scientificwriting.zip -d ~/.claude/skills/
```

### 3. ChatGPT, Gemini, бусад чатбот

1. Шинэ яриа эхлүүлж, `mn-scientific-writing/dist/mn-scientificwriting-buten.md` файлыг хавсаргана.
2. Дараах хүсэлтийг илгээнэ:

   ```text
   Хавсаргасан файлын зааврын дагуу энэ өгүүллийн удиртгалыг бичээрэй:
   [сэдэв, зорилго, эх сурвалж]
   ```

Байнга хэрэглэх бол энэ файлыг Custom GPT, Gemini Gem эсвэл Project-ийн мэдлэгийн файл болгон оруулна уу.

### 4. Codex, Cursor, Gemini CLI

```bash
npx skills add CDHI-Mongolia/cdhi-claude-skills --skill mn-scientificwriting --global --agent '*'
```

## Хэрэглэх заавар

### Материалаа бэлтгэх

Ур чадвар таны өгсөн материал дээр л бичнэ. Хүсэлтдээ хамт хавсаргана уу:

- судалгааны зорилго, арга (загвар, газар, хугацаа, түүврийн хэмжээ, ёс зүйн зөвшөөрлийн дугаар);
- үр дүнгийн хүснэгт, статистикийн программын (SPSS, Stata, R) гаралт;
- эшлэх эх сурвалж: DOI, PubMed ID эсвэл PDF;
- илгээх сэтгүүлийн зохиогчид өгөх заавар.

Word, PDF, Excel, CSV файл, хүснэгтийн зургийг хавсаргаж болно. Өвчтөний нэр, регистрийн дугаар, утас, хаягийг хасаж, нэргүйжүүлсэн өгөгдөл өгнө үү.

### Хүсэлтийн жишээ

`[ ]` доторхыг өөрийн мэдээллээр солино.

| Зориулалт | Хүсэлт |
|---|---|
| Бичих | `Удиртгал бичиж өг. Сэдэв: [...]. Зорилго: [...]. Эх сурвалж: [хавсралт]` |
| Засах | `Энэ хэлэлцүүлгийг сайжруулаач: [бичвэр]` |
| Хянах | `Энэ өгүүллийг рецензент шиг шалгаач, засахгүй: [бичвэр]` |
| Хураангуй | `Өгүүллийн монгол, орос, англи хураангуй, түлхүүр үгийг бэлтгэ: [бичвэр]` |
| Эшлэл | `Ном зүйг Vancouver стандартаар засаарай: [жагсаалт]` |
| Сэтгүүлд тааруулах | `CAJMS-д илгээх гэж байна, шаардлагаар шалгаач: [бичвэр]` |
| Монголын анагаах ухааны сэтгүүл | `«Эрүүл мэндийн шинжлэх ухаан» сэтгүүлийн загвараар өгүүлэл бичье. Өгөгдөл: [хавсралт]` |
| Тохиолдлын танилцуулга | `CARE удирдамжаар тохиолдлын танилцуулга бич. Өвчний түүх, шинжилгээ: [хавсралт]` |
| Рецензийн хариу | `Рецензентийн санал, миний өгүүлэл хавсралтад байна. Хариу захидал бич.` |
| Удирдамжаар шалгах | `CONSORT 2025-аар шалгаад хяналтын хуудсыг бөглө: [бичвэр]` |
| Англиар бичих | `Write a structured abstract for The Lancet, up to 300 words: [бичвэр]` |

Claude дээр командаар шууд эхэлж болно: `/mn-scientificwriting [хүсэлт]`. Өргөтгөлөөр суулгасан бол `/mn-scientificwriting:mn-scientificwriting [хүсэлт]`.

### Хүсэлтэд нэмж болох мөр

| Мөр | Үр дүн |
|---|---|
| `Сэтгүүл: CAJMS` | Тухайн сэтгүүлийн шаардлагаар бичнэ |
| `Хэл: англи` | Өгүүллийг англиар бичнэ, хариулт монголоор гарна |
| `Эшлэл: APA 7` | Заасан стандартаар эшилнэ |

### Хариултын бүтэц

| Ажил | Хариулт |
|---|---|
| Бичих | Эхлээд хэсгийн тойм (та батална), дараа нь үргэлжилсэн бичвэр, эцэст нь таны шалгах, бөглөх зүйлсийн товч жагсаалт |
| Хянах | Ноцтой, бага, найруулгын санал, хэсэг тус бүрээр, засварын саналтай |
| Удирдамжаар шалгах | Зүйл бүр өгүүллийн аль хэсэгт байгааг заасан хяналтын хуудас, дутуу зүйлийн жагсаалт |
| Сэтгүүлд тааруулах | Тэнцсэн, засах зүйлсийн шалгах хуудас |

## Анхааруулга

1. Өвчтөний хувийн мэдээлэл, нүүр харагдах зургийг бүү оруул. Байгууллагынхаа мэдээлэл хамгаалах журмыг мөрдөнө үү.
2. Эцсийн бичвэрийн эшлэл, тоо, статистикийг эх сурвалжтай нь тулгаж шалгана уу. Бүтээлийн хариуцлагыг зохиогч хүлээнэ.
3. Ур чадвар статистик шинжилгээг орлохгүй. Шинжилгээгээ программд хийгээд гаралтаа хавсаргана уу.
4. Хиймэл оюун ашигласан тухай сэтгүүлийн бодлогыг шалгана уу. Ихэнх сэтгүүл үүнийг мэдэгдэхийг шаарддаг бөгөөд хиймэл оюуныг зохиогчоор бүртгэдэггүй.
5. Илгээхийн өмнө давхцал шалгах программаар (iThenticate, Turnitin г.м.) шалгуулна уу.
6. Монголын зарим сэтгүүлийн заавар хуучин. Сүүлийн хувилбарыг редакцаас авна уу.
7. Онош тавих, эмчилгээ сонгоход бүү ашигла. Энэ бол бичлэгийн хэрэгсэл.
8. Монгол бичвэрийн найруулгыг MN-Humanizer ур чадвараар эцэст нь нэг удаа шалгаж болно.
